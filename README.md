# 😴 Sleep Health and Lifestyle Dashboard - Power BI

## Project Overview

Developed an interactive Power BI dashboard to analyze sleep duration, BMI, stress levels, heart rate, and blood pressure. The dashboard helps identify health trends using interactive visualizations.

---

## Tools Used

- Power BI
- Microsoft Excel
- Power Query

---

## Features

- Sleep Duration Analysis
- BMI Analysis
- Blood Pressure Dashboard
- Heart Rate Analysis
- Stress Level Analysis
- Interactive Filters (Slicers)
- KPI Cards

---

## Skills Demonstrated

- Data Cleaning
- Data Transformation
- Dashboard Development
- Data Visualization
- KPI Reporting
- Business Analysis
